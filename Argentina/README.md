Leak 1 (Scaler): Previously, scaling was fit before the split, letting the model “peek” at test statistics. Now scaling is fit only on training via a Pipeline.

Leak 2 (Duplicates): Duplicate rows were contaminating train/test. We now drop duplicates before splitting.

Leak 3 (Post-Outcome Feature): last_audit_team_id is only available at the end of collaboration, so it’s dropped to avoid target leakage.
